# 🏦 Bank System

A console-based Bank Management System built using C++.  
This project simulates real-world banking operations and focuses on <strong>OOP programming and system design</strong>.

---

## 📌 Features

- 🔐 User Authentication System (Login / Logout)
- 👥 User Management (Add, Delete, Update, Find)
- 👥 Client Management (Add, Delete, Update, Find)
- 🛡️ Role-Based Access Control (Permissions)
- 💰 Account Management
- 💸 Deposit & Withdraw Operations
- 📊 Transaction Handling
- 💾 Data Persistence Using Files
- 🔄 Money Transfer Between Accounts
- ✏ Registering Login States
- 🔁 Exchange Between Currencies

---

## 🧠 Project Approach

This project is built using:

- OOP Programming principles
- Modular code organization
- Clear separation of responsibilities
- Scalable logic design for future improvements

---

## 🛠️ Technologies Used

- Language: C++
- Storage: File System (TXT / Data Files)
- IDE: Visual Studio
